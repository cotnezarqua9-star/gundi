# ⚽ Gundi — Live Football Auction Game

2–4 მოთამაშე, 4-ციფრიანი ოთახის კოდი, 5 რაუნდი, 15-წამიანი ლაივ აუქციონი.
Frontend: HTML/CSS/JS (build-ის გარეშე) · Backend: Node.js + Express + Socket.io.

```
gundi/
├── docs/            ← ფრონტენდი (GitHub Pages აქედან ქვეყნდება)
│   ├── index.html   (SEO + Open Graph ტეგები)
│   ├── style.css, app.js
│   ├── config.js    (სერვერის მისამართი)
│   ├── favicon.svg, og-image.png, robots.txt, sitemap.xml
├── server/          ← ბექენდი
│   ├── server.js    (ოთახები, აუქციონი, ტაიმერი)
│   ├── players.js   (ფეხბურთელების ბაზა — აქ შეგიძლია დაამატო)
│   ├── test/simulate.js  (ავტომატური ტესტი)
│   └── package.json
```

## 1. გაშვება VS Code-ში (ლოკალურად)

1. დააინსტალირე **Node.js 18+** (https://nodejs.org) და **VS Code**.
2. VS Code → *File → Open Folder* → აირჩიე `gundi`.
3. გახსენი ტერმინალი (*Terminal → New Terminal*) და გაუშვი:
   ```bash
   cd server
   npm install
   npm start
   ```
4. ბრაუზერში გახსენი **http://localhost:3000** — სერვერი ფრონტენდსაც თვითონ გასცემს.
5. სატესტოდ გახსენი მეორე ტაბი (ან ინკოგნიტო) და შედი კოდით.
6. **ტელეფონიდან** (იმავე Wi-Fi-ზე): კომპიუტერის IP-ით, მაგ. `http://192.168.1.15:3000` (IP: Windows `ipconfig`, Mac/Linux `ifconfig`).
7. ავტომატური ტესტი (მთელი თამაშის სიმულაცია): `npm test`.

> `config.js`-ში `GUNDI_SERVER_URL` ლოკალურად ცარიელი უნდა დარჩეს.

## 2. ონლაინ გამოქვეყნება

GitHub Pages მხოლოდ სტატიკურ ფაილებს ინახავს, Socket.io სერვერს ვერ გაუშვებს. ამიტომ ორი ნაწილია:

### ა) ბექენდი → Render.com (უფასო)
1. ატვირთე მთელი `gundi` საქაღალდე GitHub-ზე (რეპო, მაგ. `gundi`).
2. https://render.com → *New → Web Service* → აირჩიე რეპო.
3. პარამეტრები: **Root Directory:** `server` · **Build Command:** `npm install` · **Start Command:** `npm start` · Plan: Free.
4. *Environment* → დაამატე `ALLOWED_ORIGINS` = `https://cotnezarqua9-star.github.io` (შენი GitHub Pages დომენი).
5. გაშვების შემდეგ მიიღებ მისამართს, მაგ. `https://gundi-server.onrender.com`.

⚠️ უფასო Render სერვერი 15 წუთი უმოქმედობის შემდეგ იძინებს; პირველ შესვლაზე გაღვიძებას ~50 წამი სჭირდება. თამაშის დაწყებამდე წინასწარ გახსენი საიტი. ოთახები მეხსიერებაშია — სერვერის რესტარტზე იშლება.

### ბ) ფრონტენდი → GitHub Pages
1. გახსენი `docs/config.js` და ჩაწერე:
   ```js
   window.GUNDI_SERVER_URL = 'https://gundi-server.onrender.com';
   ```
2. GitHub რეპო → *Settings → Pages* → Source: **Deploy from a branch** → Branch: `main`, საქაღალდე: **/docs** → Save.
3. რამდენიმე წუთში საიტი იქნება `https://cotnezarqua9-star.github.io/REPO/`.

## 3. SEO და Google Search Console

1. `docs/index.html`, `docs/robots.txt`, `docs/sitemap.xml`-ში ყველგან ჩაანაცვლე `cotnezarqua9-star` (და საჭიროებისას `/gundi/` — რეპოს სახელი) შენი მონაცემებით. VS Code-ში: `Ctrl+Shift+H` (Find & Replace in Files).
2. https://search.google.com/search-console → *Add property* → **URL prefix** → ჩასვი შენი საიტის მისამართი.
3. დადასტურება: აირჩიე **HTML tag** → დააკოპირე მოცემული `<meta name="google-site-verification" ...>` და ჩასვი `index.html`-ის `<head>`-ში (იქ დაკომენტარებული მაგალითია) → push → *Verify*.
4. *Sitemaps* → ჩაწერე `sitemap.xml` → Submit.
5. *URL Inspection* → ჩასვი მთავარი URL → **Request indexing**. ინდექსაციას რამდენიმე დღე შეიძლება დასჭირდეს.
6. Open Graph-ის შესამოწმებლად: https://developers.facebook.com/tools/debug/

## 4. თამაშის წესები (როგორც რეალიზებულია)

- ყველას აქვს **$1,000,000** და **5 სლოტი**: მეკარე, მცველი, ნახევარმცველი, თავდამსხმელი და **ლეგენდა** (ბოლო რაუნდი — ყველა დროის უდიდესი ფეხბურთელები, `LEGENDS_RAW` ჩამონათვალი `server/players.js`-ში).
- რაუნდში ბარათების რაოდენობა = მოთამაშეები + 2. ყოველ ბარათზე **15 წმ**; ბოლო 3 წამში დადებული ფსონი ტაიმერს 3 წამამდე აბრუნებს (anti-snipe).
- მინიმალური ნახტომი $10,000; საწყისი ფასი ყველა ფეხბურთელზე **$40,000** (`START_PRICE` `server/players.js`-ში).
- რაუნდში **ერთ ფეხბურთელს** ყიდულობ. ვისაც ვერაფერი შეხვდა, უფასოდ იღებს გაუყიდავს ან „აკადემიელს“ (60 რეიტინგი) — გუნდი ყოველთვის სრულია.
- ბიუჯეტიდან ყოველი დარჩენილი ცარიელი სლოტისთვის მინიმუმ $40,000 რჩება დაცული.
